# Golf groups

**You get:** new golf groups for every round, so everyone plays with as many different people as possible.

**Status:** live


**The problem.** Golf trips and leagues want new groups each round, so everyone plays with
everyone and nobody gets the same partners again. Organizers ask for help on forums year after
year ([Math Central](https://mathcentral.uregina.ca/QandQ/topics/golf%2020),
[The Sand Trap](https://thesandtrap.com/forums/topic/64321-golf-pairings-software)).
Free answers are rare. One site [sells spreadsheets](https://probablegolfinstruction.com/tournament-pairings-sample-spreadsheet.html)
for $12 to $45.

**What the page does.** Type names (or just a number of players), the group size and the
number of rounds. It makes groups for every round with as few repeats as it can find, marks
any repeat, and lists who played with whom. Copy or print the result. It works offline and
keeps your list only in your browser.

**What already exists.** golfsoftware.com has a free online pairings generator (numbers, group
size, rounds, a who-played-with-whom view); spreadsheets sell for $12 to $45. **Why an asker is
better off here:** real names, any group size with an honest leftover group, repeats marked, copy
and print, and it works offline on a phone at the first tee.

**What is fake or missing.**
- It searches for a good mix. It does not prove a perfect mix exists or always find one.
- No "keep these two apart", no fixed partners, no handicap balance, no tee times.
- It does not try to spread the smaller groups fairly when players don't divide evenly.

**Pass mark.** 10 people use it for a real event by 2026-11-21. Counted from issues, comments
or messages that say so.
