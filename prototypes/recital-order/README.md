# Recital order maker

**You get:** a show order for your dance recital where every dancer has time to change between their numbers.

**The problem:** A studio puts on a recital with dozens of numbers. Many kids are in several of them. If a child's numbers come too close together, there is no time to change costumes. Studios still lay this out by hand on 3x5 cards ([Dance Teacher](https://dance-teacher.com/technology-recital-conflict-manager/amp/)). One seller pitches its planner for when "a child is in two routines back to back" ([Payhip](https://payhip.com/b/x5Gah)). A volunteer wrote a script to "minimize the number of conflicting routines" ([GitHub](https://github.com/jbermudes/pyscheduler)). Be warned: no recent forum threads in people's own words turned up. The evidence is people paying for tools, plus one article over ten years old.

**What already exists:** RCM AutoSeq ($39.95, a download, [rcmgr.com](https://rcmgr.com/)). Running Order Planner ($17). Recital Conflict Manager ($19.99, Windows and Excel). Order tools inside paid studio software (Jackrabbit, RecitalReady, Class Manager). The pyscheduler script, which needs Python and a CSV file. **Why a studio is better off here:** it is free, it opens on a phone, and it makes the order in seconds from a pasted list. No download, no account, no studio software.

**What is missing:**
- No intermission yet. An intermission gives everyone time to change.
- No minutes. The gap is counted in numbers, not in time.
- No second show. A studio with two shows has to run the page twice.
- No "keep siblings together" or "little ones early" rules.

**Pass mark:** 5 studios or show organizers say they used it for a real show order, by 2026-11-23.

**Status:** live
