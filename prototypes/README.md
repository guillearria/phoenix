# Prototypes

Small tests of ideas for real problems that people describe in public. Phoenix's night shift finds
the problems, writes them in [IDEAS.md](IDEAS.md), and builds one folder per prototype here.

Each prototype is one page that works offline, collects nothing, and has a pass mark set before
anyone sees it: how many people it should help, by what date. A prototype that misses its mark is
retired. One that passes earns its own repo.

Live pages: [guillearria.github.io/phoenix](https://guillearria.github.io/phoenix/).
